# Tamburaš

Metronom, štimer i akordi za tamburaše, u jednoj web stranici.

- **Metronom**: 30–250 BPM, tap tempo, takt od 2/4 do 7/8
- **Štimer**: prim, A-brač, E-brač, bugarija, čelo, berde i gitara, s mikrofonom i referentnim tonovima
- **Akordi**: svi akordi u durskom ili molskom tonalitetu i generator progresija

**Stranica:** https://app-bonic.github.io/tamburas/

## Privatnost
Sve radi u pregledniku, bez instalacije. Zvuk s mikrofona obrađuje se samo na tvom uređaju i nikamo se ne šalje. Stranica ne koristi vanjske fontove, CDN-ove ni analitiku.

Dio zbirke [app-bonic alati](https://app-bonic.github.io/alati/).
