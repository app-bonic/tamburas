# Tamburaš

Metronom, štimer i akordi za tamburaše, u jednoj web stranici.

- **Metronom**: 30–250 BPM, tap tempo, takt od 2/4 do 7/8
- **Štimer**: prim, A-brač, E-brač, bugarija, čelo, berde i gitara, s mikrofonom i referentnim tonovima
- **Akordi**: svi akordi u durskom ili molskom tonalitetu i generator progresija

Sve radi u pregledniku, bez instalacije.
